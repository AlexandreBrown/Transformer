# ViT  
Original Paper : https://arxiv.org/abs/2010.11929  
  
My Implementation : [see Notebook](./vit.ipynb)  
Note: It uses the [high-performance PyTorch Scaled Dot Product Attention (SDPA)](https://pytorch.org/tutorials/intermediate/scaled_dot_product_attention_tutorial.html#beta-implementing-high-performance-transformers-with-scaled-dot-product-attention-sdpa). I tried to keep the code as clean as possible without sacrificing on performance.
